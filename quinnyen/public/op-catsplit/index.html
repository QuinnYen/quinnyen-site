貓咪分帳 CatSplit

旅行、聚餐的費用分攤，交給貓咪分帳。記下每筆支出，自動算出誰該轉給誰。

開始使用

以 LINE 登入使用，免費。也可由朋友分享的邀請連結直接加入。

功能

建立分帳群組

自訂圖示、底色與封面圖，用邀請連結拉朋友進來，一個群組最多 50 人。

多幣別、多人付款

出國用外幣記帳，自動換算匯率。一筆支出可以由多人分別出資。

五種分帳方式

均分、部分均分、份數、百分比、自訂金額，各種情況都能算。

最少轉帳結算

用最少的轉帳次數算出誰該轉給誰，並顯示每個人的明細，轉完可以記錄結清。

記錄與統計

類別、備註、日期、收據照片；明細可篩選搜尋，也有統計頁並可匯出 CSV。

朋友不用登入 LINE

不想登入的朋友，只要輸入名字就能加入群組，之後也可以綁定 LINE 認領自己的帳目。

怎麼使用

  1. 用 LINE 開啟貓咪分帳，建立一個群組。
  2. 把邀請連結傳給一起出遊或聚餐的朋友。
  3. 每個人隨手記下自己付的款項，選擇怎麼分。
  4. 結束後打開結算頁，照著建議的轉帳完成就好。

關於這個專案

這是我的個人 side project，自己和朋友出遊時實際在用。程式與設計上花了不少心思在權限控管（收據照片只有群組成員看得到）與訪客身分的設計上。
